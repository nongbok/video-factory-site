video-factory

video-factory는 채널 운영자 본인이 직접 만든 YouTube 쇼츠를 본인의 YouTube 채널 하나에 예약 업로드하는 개인용 도구입니다. 운영자 본인의 컴퓨터에서만 실행되며, 다른 사용자에게 제공하지 않습니다.

하는 일

  • 운영자가 준비한 영상 파일과 제목·설명·태그·공개 시각을 확인합니다.
  • YouTube Data API v3 (videos.insert)로 운영자 본인 채널에 비공개 예약 업로드합니다.

이 도구는 YouTube API 서비스를 사용합니다. 요청하는 권한은 youtube.upload 하나뿐입니다.

video-factory is a personal tool that schedules uploads of YouTube Shorts, made by the channel owner, to the owner's own single YouTube channel. It runs only on the owner's computer and is not offered to any other users.

What it does

  • Validates the video file and the title, description, tags and publish time prepared by the owner.
  • Uploads the video as private with a scheduled publish time to the owner's channel via the YouTube Data API v3 (videos.insert).

This tool uses YouTube API Services. The only permission it requests is youtube.upload.
