video-factory

video-factory는 채널 운영자 본인이 직접 만든 YouTube 쇼츠를 본인의 YouTube 채널 하나에 올리는 비공개 도구입니다. 운영자의 컴퓨터에서 돌아가는 웹 화면에 운영자만 로그인해서 쓰며, 다른 사용자에게 제공하지 않습니다.

하는 일

  • 운영자가 올린 영상과 제목·설명·태그·공개 설정을 확인합니다 (길이 3분 이하, 세로 영상).
  • YouTube Data API v3 (videos.insert)로 운영자 채널에 업로드하고, 결과를 화면에 보여 줍니다.

이 도구는 YouTube API 서비스를 사용합니다. 요청하는 YouTube 권한은 youtube.upload 하나뿐입니다.

video-factory is a private tool for the channel owner to upload YouTube Shorts they made to the owner's own single YouTube channel. Only the owner signs in to the web interface, which runs on the owner's computer. It is not offered to any other users.

What it does

  • Validates the submitted video and its title, description, tags and visibility settings (3 minutes or shorter, vertical).
  • Uploads it to the owner's channel via the YouTube Data API v3 (videos.insert) and shows the result in the interface.

This tool uses YouTube API Services. The only YouTube permission it requests is youtube.upload.
