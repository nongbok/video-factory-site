개인정보처리방침

시행일: 2026년 11월 7일

video-factory(이하 "이 도구")는 채널 운영자 본인만 쓰는 비공개 업로드 도구입니다. 운영자의 컴퓨터에서 돌아가는 웹 화면에 운영자만 아는 계정으로 로그인해서, 운영자의 YouTube 채널 하나에 영상을 올립니다. 이 도구는 YouTube API 서비스를 사용합니다.

1. 접근하는 정보

운영자 계정에 대해 Google OAuth 로 https://www.googleapis.com/auth/youtube.upload 권한과, 연결한 계정을 확인하기 위한 기본 권한(openid, email)만 받았습니다. 이 권한으로 운영자 채널에 영상을 올리는 일만 하며, 다른 YouTube 데이터나 Google 계정 정보는 읽지 않습니다.

2. 처리하는 정보와 사용 방법

  • 운영자가 웹 화면에 올린 영상 파일과 제목·설명·태그·공개 설정: 운영자 채널에 업로드하는 데만 씁니다.
  • 작업 기록(제목, 공개 설정, 진행 상태, 업로드된 영상 ID, 실패 이유): 업로드 결과를 화면에 보여 주는 데만 씁니다.
  • 로그인 쿠키: 로그인 상태를 유지하는 데만 씁니다 (최대 30일).

광고, 분석, 프로필 작성 등 다른 목적으로 쓰지 않습니다. 분석 도구나 추적 쿠키는 쓰지 않습니다.

3. 저장

  • OAuth 갱신 토큰은 운영자 컴퓨터의 로컬 설정 파일에만 저장하며, 브라우저로 보내지 않습니다.
  • 올린 영상 파일은 YouTube 업로드가 끝날 때까지만 운영자 컴퓨터에 임시로 보관하고, 업로드가 끝나면 지웁니다. 업로드에 실패한 파일은 다시 올릴 수 있도록 남겼다가 운영자가 지웁니다.
  • 작업 기록은 운영자 컴퓨터의 로컬 파일로만 남습니다. 별도 데이터베이스나 외부 저장소를 쓰지 않습니다.
  • 웹 화면은 Cloudflare 를 거쳐 암호화(HTTPS)된 연결로만 접속됩니다.

4. 공유

어떤 데이터도 제3자에게 판매하거나 공유하지 않습니다. 영상과 메타데이터는 업로드를 위해 YouTube(Google)로만 전송됩니다. 접속 경로 제공을 위해 Cloudflare 가 연결을 중계합니다.

5. 권한 철회와 삭제

Google 계정 권한 설정에서 언제든 이 도구의 접근 권한을 철회할 수 있습니다. 철회하면 저장된 토큰은 더 이상 동작하지 않으며, 운영자는 로컬 설정 파일에서 토큰을 지워 완전히 삭제합니다. 작업 기록과 남은 영상 파일은 운영자가 언제든 지울 수 있습니다.

6. 관련 약관

이 도구를 사용하면 YouTube 서비스 약관에 동의하는 것으로 봅니다. Google 의 데이터 처리는 Google 개인정보처리방침을 따릅니다.

7. 변경과 문의

이 방침이 바뀌면 이 페이지를 고치고 시행일을 갱신합니다. 문의는 이 사이트 저장소의 GitHub Issues 로 받습니다.

Privacy Policy

Effective date: November 7, 2026

video-factory ("the tool") is a private upload tool used only by the channel owner. The owner signs in with an account only they know to a web interface that runs on the owner's computer, and uploads videos to the owner's single YouTube channel. The tool uses YouTube API Services.

1. Information accessed

For the owner's account, the tool holds the Google OAuth scope https://www.googleapis.com/auth/youtube.upload plus basic scopes (openid, email) used only to confirm which account was connected. It uses these only to upload videos to the owner's channel. It does not read any other YouTube data or Google account information.

2. Information processed and how it is used

  • Video files and their title, description, tags and visibility settings submitted by the owner through the web interface: used only to upload them to the owner's channel.
  • Job records (title, visibility, progress, uploaded video ID, failure reason): used only to show upload results in the interface.
  • A sign-in cookie: used only to keep the owner signed in (up to 30 days).

Nothing is used for advertising, analytics, profiling or any other purpose. No analytics tools or tracking cookies are used.

3. Storage

  • The OAuth refresh token is stored only in a local configuration file on the owner's computer and is never sent to the browser.
  • Uploaded video files are kept temporarily on the owner's computer until the YouTube upload finishes, and are then deleted. Files whose upload failed are kept so they can be retried, and are later deleted by the owner.
  • Job records are kept only as local files on the owner's computer. No separate database or external storage is used.
  • The web interface is reachable only over an encrypted (HTTPS) connection through Cloudflare.

4. Sharing

No data is sold or shared with third parties. Videos and metadata are sent only to YouTube (Google) for uploading. Cloudflare relays the connection to provide access.

5. Revoking access and deletion

Access can be revoked at any time from Google Account permissions. After revocation the stored token no longer works, and the owner deletes it from the local configuration file. Job records and any remaining video files can be deleted by the owner at any time.

6. Related terms

By using the tool you agree to the YouTube Terms of Service. Google's handling of data is governed by the Google Privacy Policy.

7. Changes and contact

If this policy changes, this page will be updated along with the effective date. Questions can be sent through GitHub Issues on this site's repository.
