개인정보처리방침

시행일: 2026년 11월 7일

video-factory(이하 "이 도구")는 채널 운영자 본인만 사용하는 개인용 업로드 도구입니다. 이 도구는 YouTube API 서비스를 사용합니다.

1. 접근하는 정보

Google OAuth로 https://www.googleapis.com/auth/youtube.upload 권한 하나만 요청합니다. 이 권한으로 운영자 본인 채널에 영상을 올리는 일만 하며, 다른 YouTube 데이터나 Google 계정 정보는 읽지 않습니다.

2. 사용 방법

운영자가 준비한 영상과 제목·설명·태그·공개 시각을 운영자 본인의 YouTube 채널에 업로드하는 데만 사용합니다. 광고, 분석, 프로필 작성 등 다른 목적으로 쓰지 않습니다.

3. 저장

OAuth 갱신 토큰은 운영자 본인 컴퓨터의 로컬 설정 파일에만 저장합니다. 이 도구는 별도 서버, 데이터베이스, 쿠키, 분석 도구를 쓰지 않습니다. 업로드 결과(영상 ID)는 운영자 컴퓨터의 로컬 파일에만 남습니다.

4. 공유

어떤 데이터도 제3자에게 판매하거나 공유하지 않습니다. 영상과 메타데이터는 업로드를 위해 YouTube(Google)로만 전송됩니다.

5. 권한 철회와 삭제

Google 계정 권한 설정에서 언제든 이 도구의 접근 권한을 철회할 수 있습니다. 철회하면 저장된 토큰은 더 이상 동작하지 않으며, 운영자는 로컬 설정 파일에서 토큰을 지워 완전히 삭제합니다.

6. 관련 약관

이 도구를 사용하면 YouTube 서비스 약관에 동의하는 것으로 봅니다. Google의 데이터 처리는 Google 개인정보처리방침을 따릅니다.

7. 변경과 문의

이 방침이 바뀌면 이 페이지를 고치고 시행일을 갱신합니다. 문의는 이 사이트 저장소의 GitHub Issues로 받습니다.

Privacy Policy

Effective date: November 7, 2026

video-factory ("the tool") is a personal upload tool used only by the channel owner. The tool uses YouTube API Services.

1. Information accessed

The tool requests a single Google OAuth scope: https://www.googleapis.com/auth/youtube.upload. It uses this only to upload videos to the owner's own channel. It does not read any other YouTube data or Google account information.

2. How it is used

Videos and their title, description, tags and publish time, prepared by the owner, are used only to upload to the owner's YouTube channel. Nothing is used for advertising, analytics, profiling or any other purpose.

3. Storage

The OAuth refresh token is stored only in a local configuration file on the owner's computer. The tool uses no servers, databases, cookies or analytics. Upload results (video IDs) are kept only in local files on the owner's computer.

4. Sharing

No data is sold or shared with third parties. Videos and metadata are sent only to YouTube (Google) for uploading.

5. Revoking access and deletion

Access can be revoked at any time from Google Account permissions. After revocation the stored token no longer works, and the owner deletes it from the local configuration file.

6. Related terms

By using the tool you agree to the YouTube Terms of Service. Google's handling of data is governed by the Google Privacy Policy.

7. Changes and contact

If this policy changes, this page will be updated along with the effective date. Questions can be sent through GitHub Issues on this site's repository.
